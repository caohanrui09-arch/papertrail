# 可读性与连续阅读

入口：<http://127.0.0.1:8775/>。双击 `search-reading.cmd`，或在任意目录的PowerShell执行：

```powershell
& '<repo>\search-reading.cmd' start
```

后接 `status` 查看状态，`stop` 停止本版，`start --no-open` 仅启动服务。首次启动等待目录与依赖导入就绪。

检索后选一篇论文，阅读区顶部会出现当前候选位置及“上一篇／下一篇”。它们只沿本次候选顺序移动，首尾禁用，不自动循环，也不把打开论文记为读完。加载期间可以继续下一篇；旧请求会取消并受到序号保护。

“定位在读”只滚动左侧列表，并聚焦当前标题；新论文的摘要从开头显示。候选与摘要各自支持滚轮或聚焦后的Home、End、PageDown；整页在工作台模式固定。摘要与轨迹在切换时保留各自DOM，因此切回摘要可以继续原位置。

顶栏“专注阅读”收起标题与检索区，“展开检索区”恢复检索控件，保留当前论文。在1280×720本机验收中，正文视口从291px增至514px；具体空间随窗口尺寸变化。

候选说明14px，原摘要17px，元数据与按钮同步放大，重要文字加深。47个实际配色样本最低对比度约5.486:1；只涵盖抽样的可用工作台文字，不是全站无障碍认证。首页图形和原v33视觉保留，工作台不增加入场动效。

如果读取的是合成历史中、不属于本次候选的论文，会显示“上下文论文”，禁用上下篇和候选定位，避免冒充候选顺序。修改查询／排序会清空旧摘要与导航。

核心目录、算法、模型等级与原v1核验API不变。隔离验收夹具8776仅用于延迟和503测试，交付时关闭，用户入口8775不提供其控制接口。手机和公网部署继续后置。验收与封存见reports/stage34。
