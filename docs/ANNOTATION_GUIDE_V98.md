# 人工标注规范（v98）

目标：给现有 Agent 产物补上**人工标签**，回答"引用是否支撑结论、回答是否对题、该拒答时是否拒答"，而不是继续用作者阅读代替评分。

## 数据集

- 来源：本机 `data/` 下的真实运行结果（10 个实验台作业 + 5 个自定义任务 + 32 次追问），由 `scripts/build_annotation_sheet.py` 抽取。
- 规模：**33 条**（17 条 Agent 提交、16 条读后追问；其中 8 条拒答、9 条没有引用）。
- 文件：`data/annotation/labels_v98.csv`（UTF-8 with BOM，Excel 可直接打开）。
- 旁注：`data/annotation/meta_v98.json` 记录每条的来源、策略、耗时——**标注时不要看**，避免被"这是哪个策略"影响判断。
- 不在公开仓库：引用原文来自冻结目录（不可再分发），标注表只留在本机；规范与脚本是公开的。

## 表结构

| 列 | 含义 |
|---|---|
| `item_id` | 编号 L001…L033（不要改） |
| `kind` | `agent`（任务提交）或 `followup`（读后追问） |
| `task_or_question` | 当时的任务指令或追问问题 |
| `answer` | 模型提交的回答原文（**不要修改**） |
| `evidence` | 回答引用的原文句子（可能为空） |
| `flags` | 自动标记：`refusal`（拒答）、`no_citation`（无引用）、`incomplete`（未完成协议） |
| `support_0_2` | **你要填**：引用是否支撑回答 |
| `relevance_0_2` | **你要填**：回答是否对题 |
| `citation_ok_Y_N` | **你要填**：引用本身是否合法 |
| `refusal_ok_Y_N_NA` | **你要填**：拒答是否恰当 |
| `notes` | 可选：一句话理由或边界情况 |

## 评分锚点

### support_0_2（引用 → 回答）

- **2**：引用句子直接支撑回答的主要结论（读完引用就能同意回答）。
- **1**：相关但不充分——引用只支撑部分，或需要额外推理才成立。
- **0**：引用与回答无关、答非所引，或 `evidence` 为空但回答有实质内容。

### relevance_0_2（回答 → 任务/问题）

- **2**：直接回答了任务/问题（问什么答什么）。
- **1**：相关但没答到点上（例如问"局限"却复述"提出了什么"）。
- **0**：答非所问，或拒答了一个本可以回答的问题。

### citation_ok_Y_N

- **Y**：引用里的原文句子确实来自被引论文，且与回答对得上。
- **N**：引用伪造、张冠李戴、`evidence` 为空却有实质回答，或引用了未读论文。
- 拒答且无引用 → 填 **Y**（拒答本来就不该有引用）。

### refusal_ok_Y_N_NA

- **NA**：这条不是拒答。
- **Y**：拒答恰当——问题确实无法用已读证据回答。
- **N**：拒答不当——证据里其实有答案，或问题本可回答。

## 操作流程

1. 用 Excel 打开 `data/annotation/labels_v98.csv`；
2. 按 `item_id` 顺序逐条判断，四个空列都填（拒答条目 `support/relevance` 可填 0/0 或按实际情况）；
3. 每条 30–60 秒，33 条约 **30–45 分钟**；
4. 不要改 `answer`/`evidence`；不确定就在 `notes` 写一句；
5. 存回原文件（保持 CSV 格式，别存成 xlsx）；
6. 标完告诉我，我跑 `scripts/score_labels.py` 出统计。

## 我们会怎么用

- 报告四个指标：引用支撑率（support≥1 的比例、support=2 的比例）、回答对题率（relevance≥1）、引用合法率（`citation_ok=Y`）、拒答恰当率（`refusal_ok` 中 Y/(Y+N)）；
- 按 `kind` 分开报（Agent vs 追问），并给出样本量与置信区间；
- 若有两个标注者，先算 Cohen's κ，再合并或讨论分歧；
- **不会**把标签结果说成"模型质量提升"——它只是一次静态评测。

## 已知局限

- 33 条，单任务域（多为 3D 生成论文），**不是随机样本**；
- 标注对象是"证据是否支撑回答"，不是"论文结论是否真实"；
- 无法覆盖未发生的行为（例如改写检索词从未被模型使用）；
- 标注者只有作者时，属于自评，需在报告中注明。
