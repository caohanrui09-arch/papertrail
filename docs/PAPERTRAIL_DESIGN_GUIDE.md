# Papertrail：五站设计学习与落地准则

2026-10-29。基于用户列出的Motion Sites、React Bits、Uiverse、Anime.js、Aceternity UI，阅读官方文档、组件源码及许可后形成的设计建议。本轮只学习和记录，没有重做网站、安装库或复制组件。Motion Sites暂按MotionSites.org理解。

外网动态预览两次加载超时，Uiverse主页抓取也超时。本轮不能声称五站逐个完成视觉与动效实测；可核实部分是官方栏目、文档、源码和许可证。下面布局与参数均是对本项目的建议，不是复刻某站实测值。

## 从源码学到的工程细节

React Bits的[SpotlightCard](https://github.com/DavidHDev/react-bits/blob/main/src/content/Components/SpotlightCard/SpotlightCard.jsx)并非只是增加渐变：它处理指针和键盘focus、可见性、低动态偏好、动画帧循环及事件清理。应学习的是完整生命周期和可访问性，不能只取视觉层。源码中存在持续环境动效选项；论文卡片建议默认关闭常驻漂移。

[AnimatedList](https://github.com/DavidHDev/react-bits/blob/main/src/content/Components/AnimatedList/AnimatedList.jsx)在已读部分中区分明暗主题、选中与悬浮色、渐隐遮罩、键盘导航参数和图标依赖。对检索页应保留列表位置与可读性，避免文字跟随指针大幅偏移。此处未声称审查完整组件或测过兼容性。

Aceternity的[Stateful Button](https://ui.aceternity.com/components/stateful-button)用异步点击事件衔接加载与成功。我们还必须增加失败／空结果语义：HTTP完成不等于找到满足需求的论文；动画结束也不能自动显示“已完成研究”。工具轨迹的节点必须对应实际检索、重排、原摘要核验事件，不能靠固定计时器伪造进度。

## 适合当前项目的方向

建议延续目前暖白、墨绿的阅读基调，增加更明确的层次与精细状态。介绍页和工作区承担不同任务：介绍页讲项目能力及可核验证据，工作区保持高效检索和长文本阅读。

- **介绍页**：一个有主次的标题区＋真实可操作预览＋三块能力说明。生成式检索、冷启动推荐、证据Agent的实验结果必须附适用范围，不编造采用者logo、用户数或效果数字。
- **搜索面板**：搜索按钮提供待机、进行中、空结果、失败、已返回候选等明确状态；高级方法与合成历史收进二级控制，降低首屏负担。
- **结果卡片**：标题、匹配主题、版本和来源有固定阅读顺序。悬浮只改变边框、阴影或轻微背景；真正选中时才加强视觉权重。模型等级依然明确标识来源。
- **阅读器**：打开时做一次短过渡，滚动阅读后保持稳定；更换论文保留布局位置，引用入口固定。长段摘要不逐字出现、不反复弹跳。
- **轨迹**：把JSON默认折叠，先展示“检索→候选内排序→摘要核验”及真实数量；展开后才显示参数。失败节点有具体原因，成功节点不暗示相关性已经人工验证。

先改控件状态、卡片层次、阅读器和轨迹，再考虑介绍页构图。大片粒子背景、全屏光束、长距离视差或常驻3D旋转对长文本阅读帮助有限，暂不作为工作区优先项。

## 动效建议与验收

下列数值是初始设计预算，需要新版本实测，不是已经取得的性能指标：

| 交互 | 初始建议 | 验收重点 |
| --- | --- | --- |
| 按钮hover／focus | 120–180ms的颜色和边框变化 | 键盘可见focus与鼠标同样清晰；状态不只靠颜色 |
| 首次结果出现 | 180–260ms，最多前6项，间隔约30–40ms | 内容先可访问，动画不拖延操作；再次排序不反复整屏入场 |
| 阅读器切换 | 160–220ms淡入或小幅位移 | 不改变摘要的稳定阅读位置，不造成明显布局跳动 |
| 侧栏选中项 | 140–200ms轻量背景过渡 | 不用动画延迟真实选中状态；控制项可连续操作 |
| 工具轨迹节点 | 真实请求完成后短暂强调 | 不虚构百分比、等待时长或“成功”结果 |

必须支持prefers-reduced-motion：移除装饰性移动与错峰，保留即时状态；脱离视口／切后台时停止不必要的动画，组件卸载清理事件与RAF。默认优先opacity/transform，避免对布局尺寸持续动画；渐变、阴影和blur也需实测重绘成本。不能预先承诺60fps或零性能损耗。

之后实现要保留桌面原操作：主题切换、两检索方法、同跨合成场景、自由查询等级隔离、无结果／失败、原v1摘要与来源、键盘操作。记录实际首屏、请求到可操作结果的时延和浏览器错误，检查横向溢出与阅读对比度。手机布局依用户此前要求留到后续，不冒称已验收。

## 许可与复用决定

- React Bits当前[LICENSE.md](https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md)为MIT加Commons Clause；允许嵌入应用的使用与单独再分发组件不是同一许可范围。不能沿用旧介绍中“纯MIT”的说法，也不能把当前文件自动套到旧版本或Pro资源。以后选中具体文件时固定版本、附全文许可并记录Preact适配修改。
- Uiverse的[Galaxy归档](https://github.com/uiverse-io/galaxy/blob/main/LICENSE)为MIT。保留许可证要求的声明，另记录具体作者与元素链接；归档授权不自动涵盖任意站内第三方素材。
- Anime.js当前[许可证](https://github.com/juliangarnier/anime/blob/master/LICENSE.md)为MIT；若引入则固定版本并直接调用其API，不重写时间轴引擎。
- Aceternity存在免费组件与Pro资产。已读[Pro许可](https://ui.aceternity.com/licence)对终端产品与单独模板/源码再分发作了区分；免费不自动等于统一MIT，取用时检查对应文件与依赖条款。
- MotionSites是设计提示词／素材目录；本轮只借鉴信息组织，不复制会员内容或宣称源码可自由再分发。

本轮只阅读，无新增组件复制、安装、付费或发布。当前网站文件属于已封存资产；后续实现应在新前端版本中完成，保持服务与算法可对照。
