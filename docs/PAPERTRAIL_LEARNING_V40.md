# 入门阅读版 v40 使用说明

本地地址：http://127.0.0.1:8785/ 。仍是本机服务，尚无可发给异地访客的公网链接。

在任意PowerShell目录运行：

```powershell
& '<repo>\papertrail-learn.cmd'
```

入口支持 `status`、`stop`、`start --no-open`。

## 从第一篇开始

1. 点击“开始入门阅读”或任意专题卡片。先看路径的目标与“读之前，需要哪些基础？”；每条路径3篇，可按顺序也可跳读。
2. 点击论文标题或“阅读原摘要”，右侧出现完整v1摘要和阅读问题。“继续深入时，看什么？”内有深入提示与对应原摘要片段。
3. 收藏感兴趣的论文，到“我的推荐”查看实际内容推荐与贡献项；不喜欢的论文可屏蔽。路径顺序是编辑建议，个人推荐是另一个计算过程。
4. 有自己的问题时，点击“我已有问题，直接搜索”或侧栏“自由搜索”；输入英文核心词。“调整搜索方式”保留BM25/TF-IDF和明确标注的合成上下文选项。
5. 继续使用原来的收藏备份/导入/撤销等能力。打开摘要不记录为读完或掌握知识。

三条路径为检索、冷启动和曝光评价，覆盖9篇既有目录论文。全部目录仍为162篇；没有增加数据源或更改算法和排名。阅读路径不等于完整Agent课程，教学效果未经过真人验证。

## 已有收藏与运行方式

v40沿用 `data/stage39-visitors` 的同一私有库和session.key，目录SHA与Cookie名称均不变。原浏览器在相同主机127.0.0.1访问新端口可以继续访问已有空间。localhost与127.0.0.1是不同Cookie主机，换主机/浏览器请使用备份迁移，不要以为收藏丢失。

v39和v40使用同一卷的单实例文件锁，不能同时启动。当前已停止8782的v39试用进程，改为运行8785；v39文件和部署包保持封存。如需回退，先 `papertrail-learn.cmd stop`，再 `papertrail-trial.cmd start`。不要删除数据库或session.key。旧8780工作台没有改动。

运行时继续使用Python3.12.16及独立26包，不安装新依赖。新文件在 `deploy/stage40`；不复制v39付费Blueprint，也没有创建收费资源。免费公开部署另行适配持久存储后再验收。
