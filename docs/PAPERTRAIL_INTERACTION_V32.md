# Papertrail 交互精修版

本机入口：<http://127.0.0.1:8771/>。

在 PowerShell 中可从任意目录启动：

```powershell
& '<repo>\search-v2-polished.cmd' start
```

同一绝对路径后接 `status` 查看状态，接 `stop` 停止本版服务。`start --no-open` 只启动服务。启动器会切换到项目目录，因此不要求先执行 cd。服务首次导入依赖需要等待；不要在就绪前刷新页面。重复启动会复用已核验归属的进程。

操作顺序：检索当前主题 → 点击论文标题 → 查看完整原摘要及版本链接 → 在“本次调用”展开参数。可选择合成同主题／跨主题上下文，查看候选内排序步骤；这些上下文并非访问者个人画像。修改查询或排序设置会取消未完成请求并清空旧结果。

按钮显示待检索、请求中、实际返回数量、空结果、失败重试。论文卡片用边框和左侧色条表示选中，阅读器分别显示加载、失败和原摘要。轨迹中的“已返回”来自真实 API 响应；请求尚未返回时不模拟内部完成进度。

动效使用原生 CSS：150ms 状态过渡、210ms 卡片入场、180ms 阅读器切换。系统设置减少动态效果时禁用动画和过渡，加载图标改为静态点线环。当前验收检查了浏览器已解析的媒体规则，未切换操作系统设置实测该分支。手机布局按用户要求后置。

这是独立 v32 前端，直接复用 v30 的只读 API。目录仍为42篇开发用论文，模型摘要审查不是独立真人评价。实现及验收记录见阶段32报告；原 v30 入口8770需要另行启动。

隔离故障夹具 `scripts.polished_ui_fixture` 仅用于本机8772验收，正常启动器不会运行它。真实入口8771不提供 `/_probe` 故障控制接口。
