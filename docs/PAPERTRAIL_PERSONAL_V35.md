# 我的论文兴趣空间

打开 <http://127.0.0.1:8777/>，或双击项目的 `papertrail-personal.cmd`。任意目录PowerShell可执行：

```powershell
& '<repo>\papertrail-personal.cmd' start
```

`status` 查看状态，`stop` 停止本版，`start --no-open` 仅启动。首次等待本地目录核验完成；重复启动复用归属核对后的进程。

1. 从主题或检索框找论文，点击标题读取原摘要。
2. 在卡片或阅读器点“收藏”或“不感兴趣”。已收藏按钮可取消；已屏蔽按钮可取消屏蔽。
3. 点侧栏“我的推荐”，查看依据当前收藏计算的内容推荐。“我的收藏”和“偏好管理”可查看、修改已有偏好。
4. 最近一次本页单项操作可在提示条撤销。刷新后仍保留偏好，可在管理页修改；临时撤销按钮不跨刷新保存。
5. “重置偏好”先显示数量并确认；取消不改数据，确认后清空当前目录的偏好。

偏好由SQLite保存，浏览器通过一年有效期的HttpOnly、SameSite=Strict Cookie识别自己的空间；正常刷新可恢复。清除Cookie或换浏览器会进入另一空间。当前仅本机，不是生产账户认证或跨设备同步。

新版目录42篇，与旧万篇仅1篇ID重合。偏好库按目录SHA隔离，写入还检查catalog_key、论文ID、version_key及修订号。不会自动把旧万篇画像或合成历史当作你的收藏；旧站数据仍保留。多标签页同时修改遇到版本冲突时会加载最新偏好，用户再决定是否重试。

个人推荐直接调用旧内容模型，复用新版冻结标题/摘要TF-IDF矩阵。收藏向量相加后归一化，再按内容余弦排序，排除所有已反馈论文；只展示正分词项重合，最多6篇。不感兴趣仅排除对应推荐，不作为负向兴趣向量；搜索仍可找到原论文。没有有效收藏时明确提示先收藏，不制造热门或个性化结果。

“推荐依据”展示关联的真实收藏和部分高贡献词项；展开后可查看得分、全部词项/收藏贡献合计及偏好修订。点击关联收藏可读取对应原v1摘要。词项重合不等同语义相关性或推荐质量已获验证。

原连续阅读、独立滚动、专注阅读和原摘要来源保留。本文所述偏好只作用于固定开发目录，不写训练反馈或真人标注。验收截图使用助手生成的测试偏好，已在交付前清理；请按自己的兴趣收藏。
