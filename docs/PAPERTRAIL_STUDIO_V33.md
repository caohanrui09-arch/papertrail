# Papertrail 论文发现工作室

入口：<http://127.0.0.1:8773/>。双击项目中的 `search-studio.cmd`，或在任意目录的 PowerShell 使用：

```powershell
& '<repo>\search-studio.cmd' start
```

后接 `status` 查看状态，接 `stop` 停止本版，`start --no-open` 只启动服务。首次启动等待依赖导入和目录核验完成，重复启动复用已核验归属的进程。

首页是“发现”空间：大标题、论文轨道示意、检索框和三类主题卡。点击主题卡或侧栏主题，会用真实核心查询进入工作台；也可以修改英文核心术语后提交。当前基线不提供中文语义翻译。

工作台左侧是实际候选，右侧可在“原摘要”和“调用轨迹”之间切换。点击标题读取版本摘要；展开轨迹参数和合成阅读历史可检查实际调用。自定义查询不套用预设主题的模型等级。侧栏“新的探索”清空当前结果，“发现”与“返回发现”保留本次检索设置。

顶栏可关闭页面动效；系统减少动态偏好也由Anime.js Scope原生mediaQueries和CSS处理。动效只用于有限入场、图形和状态切换，不伪造工具进度。说明弹窗包含当前目录、时间假设与评价边界，可用Escape退出。

本版只监听本机，复用原42篇目录、BM25/TF-IDF、候选内画像排序与原v1摘要API。合成历史不是个人收藏；模型判断不是独立真人标注；轨道不是相似度或引用网络。手机布局与多人公网部署继续后置。

设计参考和直接复用的Anime.js版本、许可与Git blob见 `reports/stage33/design-sources.json`、`vendor-source.json` 和 `web/papertrail-v33/THIRD_PARTY_NOTICES.md`。外网参考站实时预览未完成，本产品实际桌面验证及截图已单独保存。
