# Papertrail：自己的兴趣画像

新版本地址：[个人画像工作台](http://127.0.0.1:8768)。原 8767 展示版与阶段 23 文件保留。

```powershell
& '<repo>\personal-workbench.cmd' start
```

双击 personal-workbench.cmd 也会启动并打开浏览器。支持 status、stop；只控制本版本网关，不停止原论文后端。启动路径不依赖 PowerShell 当前目录。

## 使用

1. 默认选择“我的收藏画像”。输入英文主题并搜索，在论文卡片或文献面板点“收藏”。
2. 打开“我的兴趣”，点击“用当前兴趣更新推荐”。收藏论文进入兴趣表示，也从下一次未读结果中排除。
3. “不感兴趣”只过滤对应论文，不扩展为整个主题的负偏好。再次点击可撤销，也可在兴趣面板移除单篇偏好。
4. “重置我的偏好”先显示确认按钮；清空后下一次请求使用冷启动回退。旧会话、当时的偏好版本和引用轨迹继续保留。
5. 展开“为什么推荐”，查看真实的收藏论文贡献和词项贡献。点击候选仍可读取经过原响应核验的 v1 摘要。

没有有效收藏时按冻结训练期点赞数推荐，页面明确说明。设置中仍可选择训练画像和冷启动演示；它们不会使用新的个人偏好。

## 数据与算法边界

个人数据在忽略目录 data/stage24-personal：SQLite 保存当前偏好，runs 保存每次请求当时的偏好快照，reads 保存原摘要读取轨迹。这些不进入原训练、tuning、dev 或人工相关性标签。

当前目录仍是历史 10,000 篇 v1，时间边界 2025-02-23；个人偏好产生在今天。因此这是“今天的偏好作用于历史目录”的交互演示，不是用户历史推荐效果实验。词表仅在原训练截止前的 9,000 篇拟合，后续 1,000 篇只 transform；词表、IDF 和全部文档矩阵逐项哈希等于旧模型。

直接调用已有 scikit-learn 1.9.1 TfidfVectorizer、normalize、linear_kernel。把收藏文档的单位向量相加并归一化，再与候选做点积。解释为同一次得分计算的非零词项乘积，以及每篇收藏向量的得分贡献；只展示前几项，但完整贡献和保留在轨迹中。零重合时显示零分事实，不生成虚假的匹配主题。

原 AsOfBM25、UnifiedSession、fixed 和原文核验直接复用；默认没有 LLM。个人请求使用轻量文本模型，不额外拟合 SAR 稠密矩阵。所有方法的旧实验结果仍为封存事实，新增交互可运行不等于相关性提升。

## 浏览器空间

HttpOnly、SameSite=Strict 的随机 Cookie 标识本地浏览器空间；服务端仅存其 SHA256 标识。偏好、历史、导出、取消及额外来源读取按该空间检查。两个独立 Cookie 身份隔离，但同一浏览器同一站点的标签页共享空间，不是两个账户。

SQLite 事务与递增版本避免多标签页静默覆盖；冲突返回 409，页面刷新偏好后提示重试。每个空间最多 500 条偏好。当前没有账号恢复，清 Cookie 会失去访问原空间的凭据；重置偏好不删除历史快照。停止前等待正在执行的请求结束，当前没有强制关闭后的在途请求恢复保证。

## 后续顺序

第二项：已有 [人工标注指南](QUALITY_ANNOTATION.md)、24 条草稿需求及 423 个盲标候选对；新页面“人工评价准备”读取真实覆盖状态。仍需真人确认需求并判断相关性。收藏反馈不等于相关性标签，未标注项不算 0，当前不生成质量分数。

第三项：本版已补齐与个人推荐直接相关的基础解释。语义相关性、解释是否对用户有用仍需要真人评价，不用模型自产判断替代。

第四项：分享部署继续独立准备。当前仅绑定 127.0.0.1，没有公网链接。必须先选择可公开的数据、移除私人反馈和轨迹，配置远程 Python 服务、HTTPS、可靠身份与访问隔离、资源限额和并发验证，再连接静态前端。当前 Cookie 隔离不等同生产账号鉴权，不将本机地址当远程分享链接。
