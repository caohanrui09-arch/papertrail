# 论文判断与阅读工作台

打开 <http://127.0.0.1:8780/>，或双击 `papertrail-workspace.cmd`。从任意PowerShell目录运行：

```powershell
& '<repo>\papertrail-workspace.cmd' start
```

支持`status`、`stop`、`start --no-open`。只监听本机；同一浏览器、同一主机名下沿用原个人空间和偏好库。

搜索后，先扫读论文标题、年份、arXiv版本和原摘要预览，再点“阅读原摘要”核对完整内容。年份及提示明确指arXiv首次提交，不是期刊发表年份。预览取自已核验原v1摘要的前缀，最多420字符、列表显示三行；没有模型改写。模型参考收在可展开详情，仍可查看原因和证据。

标题、摘要预览和完整摘要中的浅绿色标记是当前已提交查询的字面匹配，忽略大小写；不是语义判断或相关性分数。查询按空白分词，只处理2–80字符的前24个不同词，正则元字符按字面转义。不在“我的推荐”中沿用上一条搜索的高亮。

工作台采用与首页一致的深色页眉、浅色正文和绿色选中态。左右面板独立滚动；上一／下一篇、定位在读、轨迹切换保留。右上“专注阅读”收起检索区，扩大正文空间，“展开检索区”返回。键盘聚焦不会再推动外层容器。

收藏、取消、不感兴趣、推荐解释和备份继续使用现有接口；推荐和收藏列表也展示对应原文预览。预览接口暂不可用时，显示提示和重试，不猜测年份；搜索和完整原摘要读取继续可用。

本轮没有改检索／推荐排名、领域目录、训练或人工评价记录。仍是42篇开发目录；网站可运行和视觉可读性不代表相关性收益。手机布局未在本轮重构。
