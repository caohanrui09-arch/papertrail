# Papertrail：从第一篇开始

## 产品定位

面向搜广推与 Agent 初学者的论文阅读工作台：帮助用户选出愿意继续读的一篇，理解摘要中的问题，再依据实际收藏发现下一篇。

算法研究仍保留生成式检索、推荐冷启动/融合及 Agent 实验。网站默认继续使用已验证的 BM25/TF-IDF 和内容推荐，固定工具流程；不把实验中的生成式模型或 LLM 调度包装成默认线上优势。

## 优先服务谁

知道基础机器学习概念，想进入搜索、推荐或 Agent 方向，但还不确定先读哪篇、读摘要时应关注什么的人。用户不需要已有发表成果，也不需要先训练模型。

第一版从现有有据可查的检索、冷启动、曝光评价三个专题入手，辅助理解 Agent 所调用的搜索/推荐工具和评价问题。它不是完整 Agent 课程，不承诺覆盖所有方向。

## 核心任务与这轮实施

1. 首页明确学习者和起读任务，主按钮为“开始入门阅读”；有明确问题的人可以直接进入自由搜索。
2. 选择一条路径，先看到阅读目标、先修知识和三篇编辑建议，再由用户决定打开哪篇。保留原认可的主题插画与布局。
3. 每篇提供“为什么读”“带着哪个问题读”“深入全文时找什么”；导读有对应的原摘要片段，原v1摘要仍完整显示并保留来源链接。
4. 收藏后在“我的推荐”获得依据实际标题/摘要计算的内容推荐，展示是哪篇收藏和哪些词项产生贡献。编辑顺序不充当推荐得分。
5. 用户可以跳读、自由搜索、屏蔽、撤销、重置、导出及导入。打开摘要不代表读完，更不代表已经理解。

不在首轮增加登录、课程打卡、自动知识掌握评分、在线LLM导师或大规模目录扩充。高级检索方法和合成上下文仍保留在“调整搜索方式”中，默认折叠。

## 三条路径

| 入口 | 建议顺序 | 要先理解的问题 |
|---|---|---|
| 生成式检索 | 2406.01197综述 → 2202.06991 DSI → 2206.02743 NCI | 模型到底生成什么，文档ID与训练解码如何衔接 |
| 推荐冷启动 | 2107.11803内容驱动音乐综述 → 2404.13298 MARec → 2107.05315 CLCRec | 零交互时有哪些内容信号，它们如何与协同表示连接 |
| 曝光与评价 | 1510.07025曝光建模 → 1003.5956日志离线评价 → 1602.05352选择偏差 | 没点击能否当负样本，无偏评价需要哪些条件 |

以上是编辑整理，非独立人工相关性标注，也未经学习难度或教学效果验证。音乐综述是内容分类的具体案例，不暗示音乐方法通用于所有推荐任务。摘要中的作者效果声明不等于本站复现确认。

## 如何评价定位是否有效

后续邀请真实使用者自愿完成同一个任务：“选一个专题，找到一篇愿意继续读的论文并说明原因，再查看个人推荐依据。”先记录是否完成、耗时、卡在哪一步及选文理由；与直接自由搜索做探索性对照。打开摘要或点击收藏只表示操作，不替代对论文相关性和理解程度的人工判断。

当前只做功能验收：三条路径与原文匹配、用户能读/收藏/推荐、自由搜索和备份不受损。没有用户测试结果，不宣称比谷歌学术更好、更快或提升学习效果。
