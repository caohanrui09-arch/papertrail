# v61：在线找论文

原有纸张感、绿色强调、图形首页与双栏工作台保留。左侧新增“在线找论文”，携带当前关键词进入 `/online.html`。在线页按需查询arXiv或OpenAlex，互不混淆来源排序；切换来源/年份或修改关键词后需重新提交，旧结果有明确提示，翻页暂时禁用。

## 使用

运行项目根目录 `papertrail-workbench.cmd`，打开 http://127.0.0.1:8791/online.html 。也可从原工作台左侧进入。输入英文关键词，或点“中文需求”复用原术语辅助，检查并修改建议后提交。示例“多模态快慢思考”填入 `multimodal fast slow thinking`，不会自行发起查询。

每页最多10篇，最多100页；可按年份筛选、上下页、上下篇阅读。结果有真实作者、日期、摘要及版本（来源有提供才显示）、来源链接。状态分别显示“仅题录”“有摘要”“开放全文链接”，最后一种是来源提供链接，未验证全文可达性，不在本站抓取或转载全文。摘要最多24000字符。OpenAlex摘要缺失时明确留空，其版本不冒充v1。

右侧请求记录包括本次原问题、英文查询、来源执行参数、页码、年份、获取时间、原响应SHA256和目录边界。OpenAlex日期是其发表日期记录，arXiv是首次提交；本次不把在线时间信息回填到冻结实验。谷歌学术仅作为带当前关键词的外部跳转，无抓取/代理/付费API接入。

## 本轮范围

在线搜索、原摘要/题录阅读和外部来源入口已接通。在线结果与167篇站内目录分开，**本轮尚未接入在线结果的站内收藏、笔记、备份或个性化推荐**。原有这些能力继续用于原目录。后续如统一个人库，需要新增独立版本身份映射与存储验收，不能直接把未知OpenAlex ID塞入旧arXiv v1目录。

## 来源复用和运行

- arXiv：复用既有 `lukasschwab/arxiv.py` commit `09d1b8bc3c85c6334d480fa94c310c3b729b1d01` 的Search构造器和原生lxml Atom解析器，源码和MIT许可随版本保留；不调用PDF下载器。适配层仅做固定端点传输、限速、字段映射和资源限制。
- OpenAlex：复用 `J535D165/pyalex` 的原样 `invert_abstract` 辅助函数，来源文件blob `7f8e8d4d5524698c2fa8ff4e25ff189aebc046f0`；保留MIT许可。它的整套客户端未引入，适配层直接使用官方JSON接口，避免无关实体封装及默认重试成本。
- 六个网络/解析依赖安装在本版本 `api-vendor`；requests、lxml等固定版本和跨平台轮子哈希见 `api-requirements.lock`。共享CPU/Web已安装环境不改。当前随附lxml二进制面向本机Windows/Python3.12；换系统应依据锁文件安装匹配轮子，不能复制Windows pyd到Linux。

当前使用OpenAlex匿名基础访问，未注册账号、配置支付或使用付费密钥。来源免费额度、接口规则可能变化，失败需如实显示。固定HTTPS端点、禁止重定向；不请求结果携带的任意URL。网络连接/读取超时5/12秒，正文最多2MiB并限制分块读取时间，前端40秒可取消等待。arXiv间隔至少3.1秒、单连接；OpenAlex间隔1.1秒。来源429/403进入冷却，失败不记为零结果，不自动轮换端点。

每服务进程24小时最多80次未缓存请求（重启重计）；公共元数据缓存15分钟、最多64条；同时最多一个在线来源请求。既有访客/全局/昂贵请求限制仍适用。它不是生产级持久计费系统。查询词发送给选定来源，公开元数据短时缓存在本机内存，不把私人收藏和笔记发送给来源。
