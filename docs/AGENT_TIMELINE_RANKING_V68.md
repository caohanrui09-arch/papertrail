# Agent 时间线与算法候选列表

本轮将原实验台的 JSON 主视图改为可操作的候选列表和执行时间线，保留黑白灰背景，蓝/橙/紫用于执行类型、排名变化与结果状态。入口为 http://127.0.0.1:8802/ ，论文工作台 http://127.0.0.1:8791/ 保留。

## 使用

双击 `project-agent.cmd`，或在项目根目录执行 `project-agent.cmd start`。启动需要装载冻结资产，随后打开 8802。停止使用 `project-agent.cmd stop`，仅控制 research68 的本地实例。

约三分钟演示：

1. 首次打开自动载入一条明确标为“历史真实记录”的 LLM 搜索成功记录，查看搜索、原摘要读取、校验提交，展开工具参数和返回。
2. 左侧选择原 RRF，以内容推荐为对照，查看相同画像下 Top10 的排名升降、新入与退出；展开单篇分数、协同分支支持、最近历史论文锚点和版本来源。
3. 载入“LLM 推荐 · 未提交”，查看保留的四次工具失败及没有最终提交的结果。此组三记录任务不同，不用于比较策略质量。
4. 选择固定流程与组合任务并执行，等待真实作业返回，查看两条引用。也可主动选择原 LLM 或状态约束 LLM；页面不自动运行模型。
5. “九次同条件对照”展示旧进程内受控比较；“历史排名质量”保留旧描述性 dev 边界；“重新执行九次对照”会启动真实作业，有相应成本，本轮没有自动执行该操作。

## 实际接入

- 新 `research68.server` 复用原 `AuditModel`、冻结模型、原生网关、research63.worker、工具和预算；原 research63/research66 源码保留。
- `/lab/algorithms` 仅为原生结果补充目录已有的标题、版本、发表/可用日期，顺序与分数不改。五组为推荐方法，搜索词不参与该组排序。没有把不同尺度的分数直接横向比较。
- Top10 升降只对共同出现的论文计算；不在对照 Top10 中的标为“新入”，不推测它以前在第几名。退出项单独列出。
- 时间线逐项读取 `trace.trace`，保留实际 attempt、参数、result 和 seconds。模型工具提案/约束在另一组详情展示，不当成已执行动作或内部思考。单步时长不补造成绝对时间线或模型耗时。
- 当前 worker 在单条任务结束时才写结果。运行中仅显示已等待时间和等待说明，没有虚构的逐步进度；九次作业可逐条显示已经完成的任务。
- `/lab/examples` 读取原阶段64实际 HTTP 验收文件，工具轨迹、答案、状态与成本保持原值，附完整来源文件哈希。回放不输出私有模型输入消息或原始模型输出；这些仍留在本机。原始工具参数与返回可展开。
- 候选标题、链接及原文通过安全 DOM textContent 渲染；外链仅接受 arxiv.org 的 HTTPS 地址。原 Host、同源、跨站拒绝和作业限制保持。

## 参考与复用取舍

本轮查阅 GitHub 的 Ant Design Timeline.tsx、MIT 许可，以及 shadcn/ui table.tsx、MIT 许可，对比 Aceternity Timeline 公开说明。前两者提供语义列表/表格、加载和可展开模式；直接引入将增加 React/样式及上下文适配成本，不能直接视为当前原生 DOM 页的替换件。沿用现有实验台的 DOM/fetch 与原生 ol/li/details/summary，借鉴信息层级，不复制新外部源码或安装组件包。源码与文档链接记录于 reports/stage68/research.json。
