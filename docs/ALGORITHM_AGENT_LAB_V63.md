# 算法与真实Agent统一实验台

这是项目核心链路的第一版集成，非网站改版。复用共同万篇目录、冻结训练历史、原生算法、原生smolagents和本地Qwen模型。当前访客收藏和在线新论文尚未接入本链路，不能冒充同一训练用户或生成式模型支持的ID空间。

## 核心闭环

同一问题/用户/时点 → 固定流程或真实LLM工具调度 → BM25搜索/内容个性化推荐 → 只能读取本次召回论文的原v1摘要 → 最终提交与原文引用校验。

工具六次、检索两次、读取两次；LLM最多8调用、30000输入和1280输出token。原LLM和状态约束LLM使用同一基础模型；后者保留原状态合法动作/实例schema隔离，不自动补参数、读取或替模型最终提交。模型失败、重复/非法调用和预算耗尽全保留。

新增推荐解释给出真实SAR分数、内容分数、协同分支支持、画像长度及最近历史锚点/余弦。五方法（popular/SAR/content/RRF/cold_aware）共用用户、时点、目录可用性和seen过滤；解释层必须逐方法验证原生Top10不变。不同算法分数不可直接比较大小；RRF未伪造合成得分。Agent对照全部使用content推荐，避免把算法变化归因于调度。
