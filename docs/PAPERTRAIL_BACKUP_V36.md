# 收藏备份与恢复

打开 <http://127.0.0.1:8778/>，或双击项目中的 `papertrail-backup.cmd`。在任意目录运行：

```powershell
& '<repo>\papertrail-backup.cmd' start
```

可用参数：`status`、`stop`、`start --no-open`。只监听本机。旧8777仍可用；同一浏览器、同一主机名下，新旧版沿用相同Cookie与偏好数据库，修改会相互可见。用localhost与127.0.0.1访问会进入不同Cookie空间，可通过导出导入迁移。

1. 从侧栏或个人空间工具栏打开“收藏备份”。
2. “导出备份”下载当前目录全部收藏和不感兴趣记录，文件名 `papertrail-preferences-v1.json`。可导出空备份。
3. 换浏览器或清除Cookie后，在相同目录的新空间中打开备份入口，选择JSON文件；也可展开“或粘贴备份 JSON”。
4. 选择冲突规则，点“校验并预览”，核对每篇论文ID、版本、当前值、备份值和保存后的值。此时尚未写入。
5. 点击“确认导入 N 项变化”。导入成功后，收藏、屏蔽和内容推荐一起刷新。刷新页面仍保留。

## 合并规则

| 情况 | 结果 |
| --- | --- |
| 当前没有该论文偏好 | 新增备份值 |
| 当前值与备份相同 | 保留，不重复写入 |
| 当前值与备份冲突 | 默认保留当前；也可明确选“使用备份中的偏好”并重新预览 |
| 当前有、备份没有的论文 | 两种策略均保留 |
| 空备份 | 不清空当前画像 |

全无变化时不增加修订号。导入不提供整库覆盖或清空；重置仍从旧确认入口操作。导入会清除本页单项“撤销”状态，避免旧操作误导；需要恢复时可导入事先保存的备份。

## 文件和保存边界

仅接受本站 v1 JSON 协议：format、整数schema_version、catalog_key、带时区exported_at及items；单项仅doc_id/version_key/title/source_url/preference。收藏like和不感兴趣hide互斥；不接收none、任意owner或额外字段。

最大256 KiB、500项。重复ID、重复JSON字段、未知论文、元数据或版本不符、目录不符、未知文件协议及损坏JSON均整份拒绝，不静默跳过。当前只支持固定42篇v2目录；不会自动把旧万篇目录或未来不同目录映射进来。来源链接只与当前目录比较，不按导入内容抓取外站。

文件是可阅读的JSON偏好备份，保存位置由浏览器管理；不包含Cookie、访客标识、登录凭据或实验标签，也不提供云同步。备份内容只提交到当前本机服务校验。

保存前重新核对当前修订、文件和策略；其他标签页已修改偏好，或者本地服务重启，会使旧预览失效。需重新预览并确认。整批使用一次SQLite事务，写入中途失败不会留下部分结果。偏好数据库仍在data/stage35-personal-v2，属于可变个人数据，不是冻结实验资产。

## 复核

```powershell
.\.cache\stage17\runtime\Scripts\python.exe -E -s -m scripts.verify_backup_delivery
```

已有验收收据时只读核对已封存文件。HTTP验收脚本只创建独立测试空间，并清理测试偏好；浏览器截图使用已清理的测试画像，不是你的兴趣或真人相关性评价。
