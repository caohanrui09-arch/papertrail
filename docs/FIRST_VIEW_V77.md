# Papertrail 首屏简洁化 · 阶段77

2026-11-17。目标是减少打开页面时的解释性小字，保留黑白灰底色、局部彩色插画和原有业务。

## 已交付

- 首页首屏只放主标题、一句介绍、一个“开始探索”按钮和彩色轨道插画。装饰编号、英文标语和重复说明移除；入门阅读和真实 Agent 示例移到下一屏。
- 侧栏保留搜索、推荐、收藏、阅读清单；专题与研究沿用折叠入口。首页收起偏好管理操作，进入工作台后仍可使用。数据范围、存储及图片示意说明可从右上角“说明”查看。
- Agent 初始页面突出问题输入、任务类型、示例画像和“核对需求”。任务来源、范围和历史记录可展开；未取得结果时不展示空的报告与双画像提示。
- 核对需求后自动展开服务端实际目录、时间与画像范围；检索词仍可修改，两个确认框仍须由用户勾选。没有自动提交任务。
- 真实执行、失败、恢复状态及历史回放会展开候选与阅读区；独立诊断也展开结果区，并保持与 Agent 实际候选分开。交接来源的完整问题、检索词和筛选条件可展开查看。

## 启动

在 PowerShell 中执行以下完整路径，或先进入项目目录运行同名命令：

```powershell
& '<repo>\papertrail-workbench.cmd' start --no-open
& '<repo>\project-agent.cmd' start
```

论文首页：<http://127.0.0.1:8791/>；Agent：<http://127.0.0.1:8802/>。已打开的旧页面可按 Ctrl+F5 刷新。停止时把 start 换为 stop；工作台 stop 不加 --no-open。
