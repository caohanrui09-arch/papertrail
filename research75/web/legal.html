数据、许可与访客空间

Papertrail 是论文发现试用项目，不由 arXiv 支持或背书。目录的标题、作者、摘要、标识和日期来自 arXiv 官方 API。根据 arXiv API 使用条款，描述性元数据（明确包括 abstract）采用 CC0 1.0。保留明确 v1 来源和提交时间，年份不等于期刊发表年份。PDF 和其他全文请前往来源阅读。

你的空间如何保存

网站只在当前浏览器设置随机凭据 Cookie（HttpOnly、SameSite=Strict；线上同时 Secure），服务器保存与该凭据对应的收藏、不感兴趣标记、显式阅读状态和你自行输入的纯文本笔记。其他访客使用不同凭据。没有注册账号，也不采集姓名或邮箱。持有浏览器凭据的人可以访问该空间；请勿分享 Cookie。

凭据有效期为 90 天；清除 Cookie、换浏览器或到期后不会自动找到旧空间，请定期导出 JSON 备份。收藏、偏好、阅读状态和笔记保存在服务器持久磁盘；托管平台可能依据自身政策处理基础访问日志。应用关闭访问日志，不会自动把搜索问题和摘要读取记录写成访客日志；你主动保存的需求审计另行存入自己的空间。重置偏好会删除当前空间的收藏与不感兴趣标记；阅读清单不会随偏好重置而删除，可逐篇移出；为并发版本校验保留随机空间记录。

阅读清单由你显式选择待读、在读或已读；打开摘要不会自动完成阅读，阅读状态不作为推荐信号。v3备份同时包含偏好、阅读状态和笔记；v2不含笔记，v1仅包含偏好。旧备份导入不会清空笔记。备份含你输入的笔记内容，请自行保管。导入先预览，文件之外的记录始终保留。

阅读位置另在本机浏览器保存原问题、可编辑的英文检索词、目录范围、笔记筛选词、选中论文ID和面板滚动位置，不保存结果或摘要；侧栏“清除阅读位置”只移除该本地记录，不影响服务器上的收藏和阅读清单。清除Cookie不会同时清除这份本地位置。

中文检索、需求与阅读报告

中文需求由本站领域术语表辅助生成英文检索词，不是全文翻译，也不调用外部模型。可修改建议再执行；未识别和否定表达需要检查确认。搜索自己的笔记只访问当前空间已保存的问题和疑问。

需求记录仅在你主动点击保存后写入，包含原问题、实际检索条件、当时返回的论文和可核查诊断。最多30条（含可恢复的归档），单独导出JSON审计文件；v3收藏备份不包含需求。处理状态不是相关性判断，也没有真人标注分数。

Markdown阅读报告可选1–20篇论文，预览版本来源和个人笔记后下载，最多256KiB。附带检索条件为当前页面选文上下文，不是完整历史日志。下载后的笔记和问题可被拿到文件的人阅读；可以取消附带笔记或检索条件。Markdown不能用于恢复偏好，请使用JSON备份。

当前网站167篇：历史核心162篇，加多模态快慢思考专题5篇。新增论文明确v1与首次提交时间，仅用于当前网站；历史实验仍使用原目录。新目录使用独立存储命名空间，迁移保留旧空间凭据、收藏、阅读状态和笔记，不截断文本。旧目录JSON备份可导入；原SQLite文件保留为升级时快照，不应同时运行旧版继续写入。

试用限制与评价边界

最多 200 个浏览器空间、每个空间最多500项偏好及500篇阅读记录；笔记每栏最多1000字符，整库按可导出256KiB备份预留容量限制；请求过多时显示限流提示。内容相似推荐依据实际收藏的词项向量计算，不能作为真人相关性或效果提升证明。同主题与跨主题预设上下文为合成演示，区别于你的真实收藏。运行中不调用付费 LLM、不在线抓取论文。

笔记不会自动改变收藏、阅读状态或推荐画像。未保存草稿关闭前可继续编辑或明确放弃；刷新离开时浏览器可能提示未保存修改。临时论文对比只在当前页面内存保存选择和加入时的查询，刷新后清空；对比原摘要重新从本站核验缓存读取，不发送到外部模型。

清洁阅读、专题筛选和比较依据

清洁阅读仅整理显示格式；数学公式保留TeX文本，未知或解析失败时显示原文并提示。可随时切到原始文本，原始摘要、来源、索引和模型词表不改。转换使用隔离保存的pylatexenc2.10（MIT），不执行TeX、不读取引用文件，也不解释HTML。

专题筛选依据既有收录主题，允许重叠，不等于人工相关性标签。年份为arXiv首次提交年份。搜索先应用条件再取前十，使用原索引的IDF；收藏筛选仅改变展示，阅读状态仍不影响推荐模型。过滤条件和摘要显示模式可在本机阅读位置中恢复。

5篇专题论文的“控制什么、如何选择快慢、是否需要训练”基于本站缓存的明确v1摘要整理，每个已填项目附精确原句。摘要没明确的信息留空，不据此断言不需要训练；未核实全文或复现实验。比较卡片是助手整理，不计为独立真人相关性标注。
